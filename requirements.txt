# YouTube Agent Skill

A lightweight Python skill for discovering YouTube videos, playlists, creators, and transcripts using the YouTube Data API v3.

## Features
- Search for videos by keyword or phrase
- Return normalized metadata for each result
- Fetch richer details for a specific video ID
- Search for channels and playlists
- Retrieve a video's transcript when available
- Designed for agent workflows and simple CLI usage

## Setup

1. Create a Google Cloud project and enable the YouTube Data API v3.
2. Create an API key.
3. Copy the environment file and add your key:

```bash
cp .env.example .env
```

Then update `.env`:

```env
YOUTUBE_API_KEY=your_api_key_here
```

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

### Python

```python
from youtube_skill import YouTubeSkill

skill = YouTubeSkill()

results = skill.search_videos("python tutorials", max_results=5)
print(results)

video_details = skill.get_video_details([results[0]["video_id"]])
print(video_details)

transcript = skill.get_video_transcript(results[0]["video_id"])
print(transcript[:3])

playlists = skill.search_playlists("machine learning playlist")
print(playlists)
```

### CLI

```bash
python youtube_skill.py "python tutorials" --max-results 5 --include-details --include-transcript
```

## Notes

- YouTube API usage is subject to quota limits.
- Search results depend on query quality and API quota availability.
- Transcript retrieval depends on the video having captions available.
- This skill is intentionally focused on discovery, metadata retrieval, and agent-friendly output.
